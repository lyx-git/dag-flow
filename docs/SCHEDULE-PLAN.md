## 0. 一句话结论
**插件内自研分钟级 cron 调度器 + 工作流级定时配置**：每个工作流可配多条定时；到点由调度器按「独立运行」语义调用既有执行引擎（无交互、manual 节点自动通过、写进 `.dag-flow/runs/`）；配置入口 = 画布头部 **⏰ 定时任务** 按钮 → 「定时任务」弹窗；配置存工作区 `.dag-flow/schedules.json`。
**硬前提：dsh web 需要开着**（调度器跑在宿主进程里；进程退出即停止，面板会显式提示 + 显示心跳）。

## 1. 需求 → 交付点
| 你的要求 | 落点 |
|---|---|
| 每个工作流定时执行 | 定时项按工作流名绑定，一个工作流可配 N 条 |
| 独立执行 | 每次触发独立 `runId`，不共享/不继承上一次运行状态；默认**不并发**（见 §2） |
| 兼容 cron 表达式 | 自研解析器，支持标准 5 字段：分 时 日 月 周，语法 `* , - /`；不支持 `L W #`（给中文报错） |
| 有个按钮配置 | 头部 ⏰ 按钮 → 弹窗增删改 + 启用开关 + 「立即运行一次」 |
| 配置定时任务的地方 | 弹窗内的条目列表（cron + 人类可读预览 + 上次/下次时间 + 上次结果） |

## 2. 关键设计（每项都给判据与代价）
| 维度 | 推荐方案 | 备选 | 判据 / 代价 |
|---|---|---|---|
| cron 精度 | **分钟级**（5 字段） | 支持秒级（6 字段） | 秒级要 1s tick（一天空转 8.6 万次）才有意义；定时工作流的真实场景是「每天/每小时」。**代价**：做不到"每 5 秒跑一次" |
| cron 实现 | **自研解析器**（约 150 行） | 引第三方库 | 项目红线是 R3 零依赖；只需 5 字段子集，自研可控可测（离线单测锁住） |
| 调度器载体 | **插件内 tick**（随 dsh web） | 系统计划任务（schtasks/launchd） | 系统任务拿不到工作流上下文、要用户手动配系统项 = 违反"装上就能用"；**代价**：dsh web 不开就不跑（面板明示） |
| 触发并发 | **同一工作流默认跳过**：上次还在跑 → 本次记 `skipped` | 允许并发 / 排队 | AI·图片·视频节点真实花钱，叠加触发会同时烧钱；跳过比排队更可预期（下次到点自然再跑） |
| 错过补偿 | **不补跑**：dsh 重启后只重算下次时间 | 补跑最近一次 | 重启后静默补跑 = 不可预期的花钱；要补跑可在面板点「立即运行一次」 |
| 运行输入 | 定时项可存 `inputs`（缺省取工作流参数的默认值） | 每次手填 | 定时是无人值守，必须能预先固定输入 |
| 失败处理 | 记 `lastRun.status/error` + 面板徽标；**不影响**后续档期 | 失败即停用该定时 | 一次失败不代表配置坏掉；停用会让用户以为"定时没了" |
| 精度与误差 | tick 20s，触发误差 ≤20s | tick 5s | 分钟级语义下 20s 足够；tick 越密空转越多 |

## 3. 数据模型与存储
`<工作区>/.dag-flow/schedules.json`（与 `workflow/` 同级，随工作区走；原子写复用既有 tmp+rename）：
```json
{
  "version": 1,
  "items": [{
    "id": "sch_lx8k2",
    "workflow": "全节点演示-技术简报",
    "cron": "0 9 * * 1-5",
    "enabled": true,
    "inputs": { "主题": "每日技术简报" },
    "timeoutMs": 600000,
    "concurrency": "skip",
    "createdAt": "2026-10-03T18:20:00.000Z",
    "lastRun": { "at": "2026-10-03T09:00:03.000Z", "status": "success", "durationMs": 41230, "runId": "run_xxx" },
    "nextRunAt": "2026-10-04T01:00:00.000Z"
  }]
}
```
- 工作流**重命名**联动更新 `workflow`（上一轮就有这条）。
- 工作流**删除/不存在** → 定时项标 `orphan`，面板黄字提示，**不自动删**（不碰用户配置）。
- 文件损坏 → 降级为空列表 + 日志，不阻塞插件加载。

## 4. API（复用 `route()` 注册，+4 条；现有 15 条 → 19 条）
| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/dag-flow/schedules?workflow=` | 列表（不带参数=全部） |
| POST | `/api/dag-flow/schedules` | 新增/更新一条（整条 body） |
| DELETE | `/api/dag-flow/schedules?id=` | 删除 |
| POST | `/api/dag-flow/schedules/run` | 立即执行一次（等价于真跑，UI 二次确认） |

## 5. 调度器（host 侧）
- 新文件 `src/adapter/scheduler.ts`：`startScheduler(ctx)` → 返回 disposer；`setInterval(tick, 20000)`；tick 内挑 `enabled && nextRunAt<=now` 的条目 → 调既有 `runWorkflow(name, { inputs, interactive:false })` → 写回 `lastRun` + 重算 `nextRunAt`。
- 挂 `ctx.effect(() => startScheduler(ctx))` → **effect 2 条 → 3 条**（apply-host 断言要同步）。
- 单个条目异常只记日志，**tick 永不崩**；启动时把已过期的 `nextRunAt` 直接重算（不补跑）。
- 进程内维护「正在跑的工作流」集合，用于 `concurrency: 'skip'`。

## 6. UI 形态（弹窗，沿用你定过的弹窗约定）
头部按钮排（✍️ 工作流参数 / 📂 打开新建 / 💾 保存 / ▶ 运行）后面加 **⏰ 定时任务** → 弹窗：

```
┌ 定时任务 ──────────────────────────────── 全节点演示-技术简报 ── ✕ ┐
│ ⚠ 定时执行会真实运行工作流：AI / 图片 / 视频节点会产生费用         │
│ ┌──────────────────────────────────────────────────────────────┐ │
│ │ ⏰ 0 9 * * 1-5        → 工作日 09:00        [启用 ✓]   ✕ 删除 │ │
│ │    上次 ✓ 41.2s（今天 09:00） · 下次 明天 09:00              │ │
│ │    [▶ 立即运行一次]                                          │ │
│ ├──────────────────────────────────────────────────────────────┤ │
│ │ ⏰ */30 * * * *       → 每 30 分钟          [启用 ○]   ✕ 删除 │ │
│ │    上次 — 还没跑过 · 下次 今天 18:30                          │ │
│ └──────────────────────────────────────────────────────────────┘ │
│ ····················· ＋ 添加定时 ·····················           │
└──────────────────────────────────────────────────────────────────┘
```
- 交互：**改动即自动保存**（沿用 2s 防抖自动保存）；cron 非法 → 红字中文提示且**不落盘**；行尾 ✕ 删除；底部虚线 + 加一条（默认 `0 9 * * *`）。
- cron 输入框旁实时给人类可读预览（`每天 09:00` / `每 30 分钟` / `工作日 09:00`）。
- 面板顶部显示调度器状态：`● 调度器运行中（心跳 12s 前）` 或 `○ 调度器未运行——需要 dsh web 常驻`。
- 画布节点、卡片、连线**一律不动**。

## 8. 风险与边界（先说清）
| 风险 | 说明 | 缓解 |
|---|---|---|
| **dsh web 不常驻 → 不触发** | tick 在宿主进程内 | 面板显式提示 + 心跳显示；文档写清"要常驻" |
| 无人值守花钱 | AI / 图片 / 视频节点真实调用 | 弹窗黄色提示；「立即运行一次」二次确认；只展示上次结果不自动重试 |
| 精度只有分钟级 | 20s tick，误差 ≤20s | 明确话术；要秒级需另议（1s tick） |
| cron 方言 | 不支持 `L W #`、不支持秒 | 解析失败给中文错误 + 文档列支持范围 |
| 时区 | 本机时区（不做多时区） | 面板显示"下次=本机时间" |
| 工作流改名/删除 | 定时项会指空 | 改名联动、删除标 orphan 不自动删 |
| 回退成本 | 需要能一键关掉 | 只关 `enabled`；彻底回退 = 删 4 个新文件 + 4 条路由 + 1 条 effect + 测试（与上一轮回退清单一致） |
