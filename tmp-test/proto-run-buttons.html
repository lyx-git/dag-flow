运行按钮「动态运行中」候选 · dag-flow

全部纯 CSS/SVG（零依赖、走合成层不掉帧）。每一行左侧是运行中态、右侧是跑完的恢复态。左边一直动才是对的。
现状（已实现）字符 ◌ 旋转 + 扫光
优点：改动最小；缺点：◌ 是字体字符，不同机器/字重下粗细与形状不一致。
A. 弧线旋转环 ★推荐2px 弧线环匀速旋转
语义全球共识（环形=进行中）；比 ◌ 清晰稳定；视觉重量适中。适合默认档。
B. 三点脉冲依次跳动的小圆点
最活泼、"正在思考/干活"感强；视觉重量最轻。缺点：不如环形一眼看出是"加载中"。
C. 呼吸点 + 扫光无旋转，仅脉冲与扫光
最克制高级；注意力负担最小。缺点：动态感最弱，远看不太"忙"。
D. 弧线环 + 外发光A 的强化版（按钮本身呼吸发光）
最醒目、适合强调"正在跑长流程"；缺点：比其它方案抢眼，跟 600ms 的节点状态闪烁同时出现时信息有点多。
实现成本：五个方案都一样（纯 CSS + 一个 <span>，无新依赖，transform/opacity 动画走合成层）。
我的推荐顺序：A > C（要更克制） > B（要更活泼） > D（要更醒目）。你点一个，我就照这个改，并补一条 CDP 断言锁住"图标类型 + 动画名"。
